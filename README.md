# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

先建辅料批号册，再允许开炒。炮制员在批号册登记辅料名、批号串、失效日；写清炒文书时必须从册中点选尚未失效的批号，缺选或选到已过失效日一律拒写（分别提示“缺选”/“过期”）。批号名、批号串与失效日随文书冻结，事后改正册上失效日不会改写已冻结正文。质检员可翻阅批号册与已冻结正文，但不能登册、不能开炒。登录后落地页是独占整屏的批号册页，顶栏提供“批号册 / 开炒炮制”入口。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 先登记辅料“蜜 / 批甲”，失效日设为后天；写白芍时点选该批，应成功。
5. 在批号册把批甲失效日改成昨天，再写同批，应被拒写并提示“过期”。
6. 打开第 4 步成功那笔文书，冻结正文里的失效日仍是原先的后天。
7. 未点选批号直接开炒，应被拒写并提示“缺选”；checker 看不到登册表单与开炒表单。
