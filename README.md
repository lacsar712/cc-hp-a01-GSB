# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

开炒前必须先在**辅料批号册**登记辅料批号（辅料名、批号串、失效日）。写清炒文书时只能从册中点选尚未失效的批号：缺选或选到已过失效日的批号一律拒写，并分别提示缺选或过期。批号正文随文书冻结，事后改正册上失效日不会改写已冻结的文书正文。

顶栏有「辅料批号册」入口，落地页独占整屏展示册表与失效提醒（已失效 / 3 日内到期）。炮制员可登册、改正失效日、开炒；质检员只能翻阅批号册与已冻结文书。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进「辅料批号册」，登记蜂蜜 · 蜜炙批甲，失效日选后天。
3. 回「炮制记录」写白芍清炒文书，点选蜜炙批甲，应成功（放行）。
4. 不点选批号直接写，应拒写并提示缺选。
5. 回批号册把蜜炙批甲失效日改成昨天，再写同批应拒写并提示已过失效日。
6. 打开已成功那笔白芍，冻结批号正文仍是原先失效日（后天）。
7. 再写一条温度 200 的清炒（挂有效批号），结论仍是未放行。
8. checker 登录可翻批号册与已冻结文书，但看不到登记表单与写入按钮。
